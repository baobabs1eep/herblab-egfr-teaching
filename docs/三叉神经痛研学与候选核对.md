# 三叉神经痛研学与候选核对

首页默认主题为三叉神经痛。肺癌 EGFR 仍是可选的固定教学案例，保留已有的同协议对接和双排序数据。

## 操作顺序

1. 在研究需求页确认疾病，按需填写靶点或成分，再点击开始检索。
2. 阅读题录、摘要与原文。候选名称来自文献化学实体提取，可能包含类别、对照药或与疾病无直接关系的实体。
3. 在候选页点击核对身份，或依次核对前三条。后端使用本轮缓存记录查询 PubChem、COCONUT 和 ChEMBL；填写合法基因符号时另查 UniProt。来源错误分别显示，不会伪造成功结果。
4. 明确选择一个身份记录，确认身份与研究相关性，填写依据。相似名称不能替代结构核对。选另一身份后需重新确认。
5. 进入验证方案讨论、结果回填和报告。确认记录、标识、链接、查询时间及本轮文献随候选保存并进入报告。尚未开展实验时结果留空。

## 当前边界

- 人工确认用于确定讨论对象，不代表药效、安全性或临床疗效验证。
- 新候选缺少同协议对接、热度与过滤规则/性质数据时不生成正式排名；人工确认不改变这一状态。
- TCMSP、HERB 尚未全库导入；此流程使用现有在线接口，不是完整中药候选发现或完整 ADMET 流程。
- 草稿与历史保存在当前浏览器，不自动跨设备同步；服务端检索会话一小时过期。刷新或打开历史后，需要重新检索才能发起新的身份查询。
- 不自动把实验记录发送给 AI，不自动执行实验，也不根据回填训练模型。
