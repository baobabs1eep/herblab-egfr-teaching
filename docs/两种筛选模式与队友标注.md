# 两种筛选模式与标注交接（2026-10-12）

本轮按队友确认的方案新增两种模式，不修改原提交材料。

## 模式一：文献证据排序

固定权重：临床 0.35、动物 0.25、细胞 0.20、计算 0.15、综述 0.05。每条记录必须明确文献标识、来源、证据类别、与本病相关性、支持／反对／不明确、人工核验状态、0–1 质量评分及评分依据。质量分需老师按统一量表核对；程序不生成质量分。

本轮采用防止数量累积优势的工程规则：每个类别只取人工核验、疾病相关、支持证据的最高质量分，再乘固定权重求和 ×100。缺类不重新归一化；没有合格证据为待补，不参与排名。反对证据仍单独提示，不能据总分忽略冲突。不同类别可能来自同一研究，仍须人工避免重复解释。该合成规则尚未经科学验证，正式使用需老师确认。

网页可下载模式一的 JSON 模板、导入已标注资料和导出计算记录。字段 `kind` 为 clinical/animal/cell/computational/review；`support` 为 supports/contradicts/unclear；`qualityBasis` 为质量分依据。模板保留空证据，不把候选通路假设转换成临床或动物证据。

## 模式二：独立计算多维结果

展示结构、靶点／通道、实验活性或对接、ADMET、BBB、毒性等独立结果，不强制计算总分。结构比较仍可从没有疾病文献的成分开始。活性保留实验类型、单位、协议和来源；不同条件不直接混排。BBB、ADMET 和毒性缺失保持待补；基础理化筛查不能当成完整 ADMET 或安全性。历史 EGFR 2ITW 对接示例独立呈现，不套到新疾病。

已有 structure-screen 返回的结构相似度可单独排序；未实现全库适应症预测、未知靶点预测、自动完整 ADMET/BBB/毒性模型。多维模板只保存真实结果与缺口，不合成评分。

## 两个验收案例

队友 `人工数据标记.txt` 指定三叉神经痛与Ⅱ型糖尿病。其表格已原样转为候选／通路假设，均标记待核验。

三叉神经痛：芍药苷、川芎嗪、小檗碱、黄芩苷/黄芩素、人参皂苷 Rg1/Rb1。

Ⅱ型糖尿病：小檗碱、黄芩苷/黄芩素、人参皂苷 Rb1/Rg1、黄芪甲苷、丹参酮 IIA、葛根素。

含斜线或成分组合的条目尚未拆成独立结构记录；计算前需逐个选定分子身份。NF-κB、AMPK 等通路名不能直接当作唯一蛋白编号。

队友下一步：补论文 PMID/DOI、原文出处、证据类型、相关性及质量依据；将复合成分拆分并核对 CID/SMILES；选定参考配体与人类靶点编号。只有候选／通路表尚不足以生成真实文献排名，也不足以补齐模式二的计算。
