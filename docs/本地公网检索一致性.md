# 本地与公网检索一致性（2026-10-13）

此前本地默认成功访问 PubMed，公网服务器受 NCBI 限制后自动切换 Europe PMC。相同疾病返回不同索引数量、前页论文和实体线索，并非仅前端文件未同步。

本版本默认固定 Europe PMC，使用相同的疾病规范化、检索范围、排序、年份及分页参数，不根据服务器网络条件自动切换默认来源。默认路径不请求 PubMed 或 PubTator；显式 PubMed 查询仅保留供技术比较，来源切换须显示。

化学线索来自 Europe PMC 返回的化学索引及其独立 Chemicals 注释接口。只处理本页真实文献记录，保留来源、文献编号及摘录，不从疾病名猜测成分，不将课堂候选混入实时结果。

提取状态区分已获取、部分可用、服务不可用、未提供可提取注释和没有文献记录。无实体注释不是“没有相关药物”；实体注释也不是中药身份、作用方向或疗效证据。继续加载时保留各页状态，避免后一页覆盖前面的失败或成功记录。

## 验收

部署并刷新后，在本地和公网重新开始研究（不要直接比较浏览器的历史草稿）。使用同一疾病、范围、年份、排序和页大小；查看实际来源、查询式、获取时间、前 20 条 PMID 和提取状态。数据库随时间更新，跨时间的数量变化仍可能发生；课堂严格复现应使用同一导出资料或固定课堂包。

来源：[Europe PMC REST API](https://europepmc.org/RestfulWebService)、[Europe PMC Annotations API](https://europepmc.org/annotationsapi)。该接口提供注释并不证明每篇论文都有注释，查询不可达仍需报告错误而非补零。
