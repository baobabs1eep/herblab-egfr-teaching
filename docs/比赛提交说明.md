# 比赛提交与访问检查

## 本地递交要求中的相关条目

本地《第二届全国高校“启真问智”教育教学人工智能大赛作品递交要求》在智能体类别列出：PPT 转 PDF（50 MB 内）；不少于 5 分钟的 mp4 演示视频（200 MB 内）；可选材料包括支持公网打开的智能体体验链接、Prompt 提示词文档、工作流 DSL 压缩包。末尾要求所有材料不能透露学校、姓名等个人相关信息。

GitHub 源码链接不是该条目明确列出的必交项。本项目将其作为可选的实现与复核材料；具体可填写的位置、链接形式及匿名要求仍以赛事提交系统和主办方口径为准。原比赛通知和团队任务文件不收录到提交版仓库。

## 推荐的仓库安排

- **现有协作库保留 Private**：邀请队友，保留讨论与开发历史。
- **另建匿名的公开提交版**：只包含当前代码、已核验数据、复现记录和面向评委的说明；使用新的干净历史，避免公开旧提交里已删除的文件。
- 公开版不用真实姓名或邮箱作为提交作者；还需检查 GitHub 账号主页、文件元数据、截图、日志路径和仓库说明能否识别个人或学校。仅换一个仓库名称不等于匿名。

这是一种便于满足访问和匿名要求的项目安排，不是比赛规定必须建立两个仓库。若主办方确认允许实名 GitHub 链接，也可在完成内容与历史审查后公开现有仓库。

## 评委如何访问

| 材料 | 检查方式 |
|---|---|
| GitHub 源码与证据 | 无登录窗口打开公开版链接；评委不应被要求先申请协作者权限 |
| 网页演示 | 另行检查 HTTPS 网站可用；仓库公开不会取消网站的登录保护 |
| 演示账号 | 随提交系统的评审说明单独提供，不能只写“联系项目组索取”；密码不写进公开 README |
| 腾讯元器入口 | 使用非创建者账号检查能否访问与提问；保留登录要求说明 |
| 备用录屏 | 展示候选、文献、双排序参数及问答流程，并遮去账户、姓名等个人信息 |

## 提交前核对

1. PPT、录屏和 README 对“已实现”的说法一致；没有把多 Agent 全链路、完整 ADMET 或实验验证写成已完成。
2. 固定提交版本，记录提交号；再次查看公开版目录和全部历史，确认没有私有配置或排除文件。
3. 在手机移动网络或另一台电脑上检查网页、登录、双排序和问答；检查 API 额度和服务器有效期覆盖评审期。
4. 若提交 Prompt 或工作流 DSL，从元器导出当前实际发布版本，清除密钥和个人信息。本仓库尚未包含这些导出文件，不应在提交说明中声称已经提供。
5. 保留本地提交材料副本和视频；GitHub、元器或网站访问出现问题时，评委仍有可阅读的说明和演示。

参考：[GitHub 仓库可见性](https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories)、[改变可见性的影响](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility)。
