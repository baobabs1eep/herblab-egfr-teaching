# 课堂资料与手动导入

## 三叉神经痛课堂资料

研究需求页点击「加载三叉神经痛课堂资料」，即可读取项目随附的固定资料，无需连接 PubMed 或 Europe PMC。它不是实时搜索或完整系统综述，页面标明资料日期和来源。

三篇材料分别用于研读疾病分类与证据层级（PMID 30860637）、动物模型（PMID 42174422）和甘草苷的前临床机制线索（PMID 41880679）。中文教学摘要为独立整理，非原文全文。题录通过 PubMed / Europe PMC 官方记录核对；在线发表日期可能早于卷期日期。

甘草苷附有 2026-10-09 获取的 PubChem 身份快照，CID 为 503737。它是 Liquiritin，不是 Liquiritigenin。课堂仍需明确选择记录、确认身份和相关性并填写依据；快照不证明药效。没有统一对接、热度与过滤数据时仍不产生正式排名。

IONI 神经损伤模型、FLIT-B 神经根压迫模型与临床经典三叉神经痛不能直接等同。指南用于疾病背景，动物研究用于讨论证据局限，不提供诊疗或直接实验操作指令。

## 手动导入

研究需求页可下载 JSON 模板，填写真实题录和自己整理的摘要后，选择文件并点击导入。最多 8 篇文献、20 条化学线索，每条摘要最多 1500 字符；必须有数字 PMID、题名、疾病、来源和有效资料时间。候选的 PMID 必须存在于同一文件的文献记录中。文件读入界面后，只有明确点击导入才提交给本项目后端。

用户导入资料标为未经核验，不会自动获得课堂资料的身份快照或确认状态。引用和摘要需回到原文确认。不要上传个人医疗资料、账号密钥或未经授权的论文全文。

加载或导入后可以让研习助手基于最多三条本轮题录和摘要片段回答。此时需要元器在线服务，不需要重新访问文献数据库。历史记录中可重新启用保存的资料上下文；资料保存在当前浏览器，不自动跨设备同步。
