# 匹配与惊奇度双排名

## 两榜的含义

第一榜按研究匹配分排序，不把文献数量或数据库覆盖度当作可靠性的替代指标。当前 EGFR 固定案例采用同协议 Vina 对接分数的归一化值，只是靶点计算匹配的代理，不是完整的疾病、通道或药效匹配模型。

其他候选可导入有依据的匹配分，或结构、靶点/通道、亲和力三项 0–100 子分及出处。各子分的归一化、权重、目标、评分规则版本必须说明；等权默认值仅为教学草案。缺少实际计算的数据保持待补，不能让 AI 随意补分。

第二榜在匹配分基础上加入有限的非热门参考项。它帮助观察因报道较少而容易被忽略的候选，不证明冷门候选更有效。

## 惊奇度计算

在身份、过滤和匹配达标、且热度记录口径一致的候选集合内，设候选数为 N、候选报道计数为 n，平滑参数为 α：

`qᵢ = (nᵢ + α) / (Σn + αN)`

`Iᵢ = −log₂(qᵢ)`

这里的 q 是本候选集合中的报道计数份额；论文可能同时报道多个候选，所以它不是独立论文被抽样的真实概率，也不是药效概率。I 是单候选的惊奇度，不是整个分布的 Shannon 熵。

将惊奇度在同一集合内归一化为 0–1，再计算：

`第二榜分数 = 匹配分 + 加分上限 × 归一化惊奇度`

所有热度相同或只有一个候选时，校正项为零。匹配低于门槛或过滤未通过的候选不能靠冷门加分进入排名。未检索或数据库未覆盖时，热度为 null，不是零；真实同口径检索为零时才填 0。没有热度的候选仍可进入第一榜，但第二榜保持待补。

第二榜名次变化在热度完整的共同队列内比较，避免把移除缺失热度候选造成的名次上升误认为校正效果。

## 数据与复核

每条匹配结果应记录结构/身份、评分来源、研究目标及协议或规则版本。热度应记录检索式、同义词处理、数据库、统计时间和覆盖范围。结构过滤、风险、文献证据与热度分开记录；没有文献不是过滤失败的理由。

在当前研究候选列表中导出「本轮双排名待补模板」，补充结构或通道与亲和力匹配、预设过滤结论及同口径热度后，在双排名页面导入。模板不把本轮几篇文献的数量当作全库热度，也不从“已确认相关”推断匹配分。

## 适用边界

这是一套可复算的教学与探索规则，尚未验证其对真实筛选偏置的改善程度。它只校正报道热度这一代理因素，不能自动消除名称不统一、数据库覆盖差异、实验质量差异或发表偏倚。增加候选、改变参考集合或平滑参数可能改变结果；报告必须保留原始数据、版本和参数，并展示敏感性比较。
