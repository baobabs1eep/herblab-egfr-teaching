# 统一候选与筛选工作区（2026-10-13）

候选入口合并为一个工作区，只保留一组「文献证据／独立计算」模式切换。当前研究、三叉神经痛和Ⅱ型糖尿病作为数据选择；EGFR 是独立计算示例，不能混进其他疾病。旧教学排序链接兼容跳转到候选工作区。

文献模式保留当前研究的身份与相关性核对；固定候选的证据评分仍需真实、人工核验的证据等级和质量依据。独立计算模式显示成分池、结构相似度、结合活性和多维记录，不合成总分。

计算输入、成分池、错误和结果按研究隔离。切换研究后不复用旧结果；晚返回的请求写入原研究。旧版未标明研究的浏览器计算记录不自动套入新疾病，历史原始导出仍可用于人工复核。

导入多维文件显示其原始疾病，疾病不匹配时不能作为当前结果。数据库网络限制仍需独立处理，界面统一不等于公网外部数据查询一定成功。
