# 数据库来源与当前覆盖范围

核对日期：2026-10-05。本文描述代码当前能够调用的外部来源、返回范围和核验边界；“可检索”不等于已经镜像、全库导入或完成实验核验。

## 当前覆盖

| 来源 | 当前实现 | 结果边界 |
|---|---|---|
| PubMed | 服务端按疾病（支持中文常见别名或英文名）检索；可选加入靶点或英文化合物条件 | 每次最多返回 8 条题录及摘要摘录。题录、摘要和命中数是检索结果，不是疗效结论 |
| PubTator3 | 对本次 PubMed 命中的 PMID 请求 BioC JSON，提取 `Chemical` 提及 | 机器识别结果标为“待核验”；可能是类别、对照药或溶剂，不能直接当作中药单体或已验证候选 |
| PubChem | 用户点击名称查询时，按名称请求 CID、分子式、分子量、InChIKey 和 IUPAC 名称 | 这是单个名称的身份查询，返回 `needs_review`；系统不会自动为每条 PubMed 化学提及逐条验证 |
| COCONUT | 用户点击名称查询天然产物记录 | 最多展示 5 条名称查询结果；名称可能命中衍生物或其他天然产物，需人工核对身份与来源 |
| HERB / TCMSP | 网站状态为人工查阅 | 未发现可核实、稳定的公开 API，也没有全库导入；不能声称已接入或镜像全库 |

方案文档还列出 UniProt、ChEMBL、DisGeNET、GeneCards、KEGG、PMC、DrugBank、Tox21、NPASS 等来源。目前它们没有作为本服务的自动检索接口或已核验全库，名称出现在方案中不代表当前实现已经接入。

## 已有本地教学资料

本地和 GitHub 分享版均保留肺癌 EGFR 三候选教学案例：槲皮素、木犀草素、黄芩素，以及 2ITW 对接复核、样例 PMID / PubChem 身份和排序记录。这些资料服务于固定案例，不构成通用疾病候选库。

2026-10-05 实测：本地 PubMed 查询返回 95 个命中；公网 Europe PMC 备用查询返回 27 个命中，按最近出版展示其中 8 条，包含 Liquiritin 的 PMID 41880679。两种接口索引和查询语法不同，命中数不能混用。网页提问时，服务端通过研究 ID 只向元器传入最多 3 篇摘要片段，每篇最多 350 字符；原生元器工作流本身没有自动搜索工具，网页实时检索由本地服务完成。该结果仍需回到 PMID 和原文核对。

示例核对中，PMID 41880679 的论文出现 **Liquiritin**（IONI model 语境）。Liquiritin 与 Liquiritigenin 是不同化合物，不能翻译或归并为后者；名称和化学身份必须分别记录。

## 排序边界

新疾病检索只产生题录、摘要片段和待核验化学实体，不生成新的候选排名。新病没有排序；页面原有肺癌 EGFR 三候选排序仍然保留。PubMed 命中、PubTator3 注释、名称查询、网络药理学预测和分子对接都不等于治疗有效性。

## 不能从当前覆盖范围推出的结论

- 不能因为 PubMed 没有出现在前 8 条，就说该病没有相关研究。
- 不能把 PubTator3 的化学提及当作已确认研究对象、结构或中药单体。
- 不能把一次 PubChem 或 COCONUT 名称命中当作自动验证；尤其要检查同义词、盐型、异构体和衍生物。
- 不能把 HERB / TCMSP 的网页可访问性表述为已公开 API 或已完成全库导入。
