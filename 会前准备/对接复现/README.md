# EGFR 三候选对接复现记录（教学试算，未通过方法自检）

截至 2026-09-27，三种候选已在同一受体、同一位置和同一参数下实际运行 AutoDock Vina。**这是一组真实的软件计算输出，但不能作为正式的“结合能力排名”**：用共晶药物回对接时，首位姿势没有回到晶体中的结合位置（预设检查门槛：重原子 RMSD <2 Å）。

| 结构与自检 | 共晶药物 | 首位姿势 RMSD | 结果 |
|---|---|---:|---|
| [1M17](https://www.rcsb.org/structure/1M17)，EGFR 野生型，2.6 Å | 厄洛替尼 AQ4 | 5.976 Å | 未通过 |
| [4I22](https://www.rcsb.org/structure/4I22)，EGFR L858R/T790M/V948R，1.71 Å | 吉非替尼 IRE | 3.629 Å | 未通过 |

4I22 中的 V948R 是晶体构建背景，不能直接等同病人的 EGFR 双突变体。采用 4I22 仅是独立的技术自检；**三候选分数都来自 1M17，不得和 4I22 的参考药物分数混排**。两次失败提示当前准备和评分设置需要继续排查，不能证明三个分子没有结合，也不能证明它们会抑制 EGFR。

## 可复核输入和输出

- 结构：`input/1M17.pdb`、`input/4I22.pdb`，均来自 RCSB。结构哈希及处理参数见两个 `manifest.json`。
- 1M17：只取链 A 的蛋白 ATOM，去除配体、水和其他 HETATM；格点由 AQ4 共晶重原子边界各加 5 Å 确定，中心 `(21.6975, 0.303, 52.0925)`，大小 `(26, 22, 22)` Å。
- 三候选：从[身份核验 CSV](../肺癌EGFR教学候选_首批核验.csv)中的 SMILES 出发，RDKit 生成一个中性 3D 构象，seed `20260926`，MMFF 优化 500 步。未评估质子化／互变异构体敏感性。
- 工具：RDKit `2026.3.6`、Meeko `0.8.0`、AutoDock Vina `1.2.7`。同一刚性受体、Vina 评分、exhaustiveness `16`、seed `20260926`、CPU `2`。具体准备脚本为 `prepare_inputs.py`、`prepare_reference.py`、`prepare_4I22.py`，统计脚本为 `validate_outputs.py`、`package_results.py`。
- 每个候选的 `prepared/C00x.log` 与 `prepared/C00x-out.pdbqt` 是原始日志与姿势；`prepared/results.json` 含摘要和文件 SHA-256。AQ4 的 ex64、Vinardo 和原位局部优化补充检查也保存在 `prepared/`，均未使首位全局搜索姿势通过 <2 Å 门槛。
- 第二结构的参考药物记录见 `prepared_4I22/validation.json`、`IRE_native.log` 和 `IRE_native-out.pdbqt`。

[待审的 JSON](../三候选对接试算_验证未通过_不作正式排名.json)可导入现有前端：它会展示计算分数及资料状态，但保留 `filter.status=unknown`，因此双排名合格数为 **0**。这避免把未验证试算误标成正式结论。

## 风险过滤规则草案

可以先把“基础可研究性筛查”与“安全性”分开。三者目前的 SwissADME 均预测胃肠吸收 High、Lipinski 0 违反；因此若只用这两项作**基础性质筛查**，三者均满足。但三者同时有 `catechol_A` PAINS 提示和 CYP1A2/2D6/3A4 抑制预测，不能据此说三者安全。当前材料没有统一的细胞毒性、药物相互作用或实验复测数据，也没有事先约定的排除阈值。故**综合硬过滤仍保持 unknown**，不得用基础性质的“满足”替代安全或完整 ADMET 的“通过”。

下一步最有效的是复查受体／配体准备（质子化、互变异构、晶体水及侧链、参考配体原始键型），采用已知药物进行回对接并记录首位姿势 RMSD；方法自检通过后再用同一条件重跑三个候选。届时仍需确认一致的风险过滤标准，才能生成可说明依据的常规／冷门双排名。[AutoDock Vina 官方文档](https://autodock-vina.readthedocs.io/en/stable/docking_basic.html)说明了受体、配体准备和共晶配体回对接流程。
