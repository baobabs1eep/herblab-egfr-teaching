# 数据库接入说明

本文说明当前服务的真实接入链路和数据责任。它不表示项目复制或镜像任何外部数据库。

## 服务端实时链路

1. 用户在网页输入疾病（中文常见别名或英文名），可选填写靶点或英文化合物，再点击“开始检索”。需求文字不会自动触发搜索。
2. 服务端优先尝试 PubMed E-utilities；若云端上游返回 HTML 阻止页等不可用响应，则使用 Europe PMC 官方 REST 作为 PubMed 兼容备用，并标注真实来源。单次检索最多返回 8 条题录及摘要。常见中文疾病名由服务内置映射；未收录的中文疾病名通过已配置的元器规范化为英文医学术语，并在检索结果中同时保留用户输入和实际英文检索词。自动规范化结果仍需用户核对。
3. 化学线索按当前服务实现提取并标记为待核验。PubTator3 接入代码保留，但当前云端 NCBI 上游可能返回 HTML 阻止页，因此不能声称已得到 PubTator3 的有效注释；Europe PMC 仅把非零 `registryNumber` 的化学线索作为候选提示，也不等同于 PubTator3 或结构确认。
4. 用户点击某个名称时，服务端才请求 PubChem，返回 CID、分子式、分子量、InChIKey 和 IUPAC 名称；这不是对每条 PubMed / 化学线索自动验证。当前云端 PubChem 请求也可能受 NCBI 上游限制并返回阻止页。
5. 用户点击天然产物名称查询时请求 COCONUT，可能返回名称相近的天然产物或衍生物，必须人工复核。
6. `/api/research` 返回研究结果并签发短期研究 ID。网页提问把该 ID 交给 `/api/chat`；服务端从研究记录中挑选最多 3 篇题录，只传每篇最多 350 字符的摘要片段和必要来源字段给元器。原生元器工作流没有自动搜索工具，外部检索由网页服务完成。

官方入口：PubMed <https://www.ncbi.nlm.nih.gov/books/NBK25501/>；Europe PMC REST <https://europepmc.org/RestfulWebService>；PubTator3 <https://www.ncbi.nlm.nih.gov/research/pubtator3/>；PubChem <https://pubchem.ncbi.nlm.nih.gov/>；COCONUT <https://coconut.naturalproducts.net/>。

## HERB 与 TCMSP

HERB 和 TCMSP 当前仅列为人工查阅来源。没有核实的公开、稳定 API，也没有把其全库导入项目。接入前须确认导出授权、版本、字段许可和引用要求；网页能访问不等于允许批量复制。

## 证据与名称边界

机器化学线索可能是类别、对照药、溶剂或其他论文实体。PubChem 名称查询可能返回同义词、盐型或其他身份；COCONUT 名称查询可能返回衍生物。结果都应回到 PMID、原文和结构数据库逐条核验。

三叉神经痛实测（2026-10-05）：本地 PubMed 查询为 95 个命中；云端 Europe PMC 的 SRC:MED / TITLE_ABS 备用查询为 27 个命中，按最近出版展示 8 条题录。两种接口索引和查询语法不同，不把命中数混用。PMID 41880679 的相关名称是 **Liquiritin**，并处于 IONI model 语境；不得与 Liquiritigenin 混为一谈。

## 排序和元器边界

新疾病只产生检索记录，不生成新排名；新病没有排序，原有肺癌 EGFR 教学排序继续保留。排名数据来自固定教学案例，不能外推到新疾病。

元器可回答网页传入的外部资料片段，但资料片段不是完整原文，也不是自动核验结果。回答必须保留 PMID、来源和“需核对原文”的边界，不得把候选、化学身份或疗效写成已验证事实。
