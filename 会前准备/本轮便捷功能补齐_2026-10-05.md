# 本轮便捷功能补齐（2026-10-05）

本轮在已有实时检索和 EGFR 三候选教学排序基础上，补齐网页学习记录流程；不等于原始多 Agent 规划全部完成。

- 实时文献结果可记录证据类型、模型、笔记及人工阅读状态。阅读勾选不表示实验验证。
- 化学线索可选作当前讨论对象，携带疾病、查询式、检索时间、PMID 和来源快照进入实验设计及结果回填。
- 外部候选按疾病和分子标识隔离草稿。实验设计增加资源、重复、分析方法、判定标准；讨论提纲只填空字段。
- 研究记录可导出和导入 JSON，导入记录视为用户材料，不成为服务端已检索证据。浏览器草稿不跨设备自动同步。
- 完整报告按当前对象显示并可导出 TXT、浏览器打印或保存 PDF。没有真实实验时结果保持空白。
- 新疾病没有对接、热度、过滤数据时不生成排名，也不套用 EGFR 排名。

仍未完成：完整 8 Agent 调度、50–100 或更多候选的统一核验库、第二固定案例、完整 ADMET/毒性评价、机制网络、自动实验统计与反馈、集中学习管理。TCMSP/HERB 仍为人工核对入口，未全库导入；云端 NCBI 访问限制仍存在，文献使用 Europe PMC 官方备用来源。
