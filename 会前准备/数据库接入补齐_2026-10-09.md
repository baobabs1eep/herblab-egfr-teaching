# 数据库与文献库接入补齐

原规划核心候选来源：TCMSP、HERB、COCONUT；文献：PubMed/PMC；标准化：PubChem、UniProt；ChEMBL 是可选活性增强来源。

## 新增接口与网页入口

| 接口 | JSON 输入 | 返回 |
|---|---|---|
| POST /api/target | {"query":"EGFR"} | UniProt 人类人工审阅靶点身份、功能和来源 |
| POST /api/chembl-molecule | {"name":"Quercetin"} | 最多 5 条 ChEMBL 身份候选及结构，需用户确认 |
| POST /api/bioactivity | {"moleculeId":"CHEMBL50"} | 最多 20 条活性，含测量类型、关系、值、单位、实验、物种、靶点和文献 |
| POST /api/article | {"pmid":"24471765"} | Europe PMC 精确文献核对、摘要、DOI、PMCID、开放获取状态和原文入口 |

研究需求和文献页新增查询面板，文献行支持 PMID 核对，查询结果可导出 JSON。仅查身份和实验记录，不自动推断疾病靶点，不把不同条件活性混合排名。全文入口不等于全文证据抽取。元器知识库不会自动获得新查询结果。

## TCMSP/HERB 真实状态

TCMSP 官方旧站下载页：<https://old.tcmsp-e.com/load_intro.php?id=31>。本次实际请求其 03_Info_Molecules.xlsx 返回 HTTP 200、Content-Type text/html，内容不是 XLSX。因此未取得真实数据包，也未导入全库。HERB 未核实正式 API 或可获取的全库导出。

新增本地 JSON 导入工具，输入必须是获准使用、已整理为标准字段的真实数据：

```sh
node 本地服务/import-candidates.cjs input.json imported.json --source TCMSP --version 2.3 --source-url https://old.tcmsp-e.com/load_intro.php?id=31 --retrieved-at 2026-10-09T00:00:00Z
```

标准字段：candidateId、name 必填，smiles、sourceHerb、targets、literatureIds 可缺失。保存原文件 SHA256、版本、来源链接、获取时间、导入时间和 needs_review 状态；不覆盖输出，拒绝 HTML 错误页和重复 ID。仅 JSON，不直接支持 Excel；输出是版本化文件，不是已建后端候选数据库，也不会自动接入双排序。

## 验证及部署边界

官方实时查询已返回：UniProt EGFR → P00533；ChEMBL Quercetin → CHEMBL50；CHEMBL50 活性命中 2978、展示 20；PMID 24471765 → 真实题录与 PMCID。

端到端本地 HTTP target、bioactivity、article 返回 200；一次 chembl-molecule 超时，界面保留错误提示，不能把超时当零结果。固定 API 域名、输入校验、超时、有界缓存及既有限流保留。

本次尚未执行公网服务器部署，公网网站仍是原版本。服务器 /opt/herblab 不是 Git 仓库，不能直接 git pull；备份后更新前端、server.cjs、research.cjs 和新增 sources.cjs，保留原 .env，再重启。旧的只复制 server/research 命令不足以部署本轮模块。

官方文档：<https://www.uniprot.org/help/api_queries>、<https://chembl.gitbook.io/chembl-interface-documentation/web-services/chembl-data-web-services>、<https://europepmc.org/RestfulWebService>。
