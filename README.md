# 中药单体筛选研学助手（EGFR 教学案例）

本仓库包含前端页面、Node 服务、双排序程序、教学案例资料与可复核的对接试算记录。[公网演示站](https://43.129.169.13/)已部署，访问账号请向项目组索取；仓库不保存访问密码或腾讯元器 API 密钥。腾讯元器智能体的[在线体验入口](https://yuanqi.tencent.com/webim/#/chat/vcaDuu?appid=2103722870126603328&experience=true)也可单独使用。

## 本地运行

1. 安装 Node.js。在 `本地服务` 目录将 `.env.example` 复制为 `.env`，把 `YUANQI_APP_KEY` 填为自己账号的元器密钥；不要提交 `.env`。
2. 在项目根目录执行 `node 本地服务/server.cjs`，浏览器访问 <http://127.0.0.1:8787/>。Windows 可双击 `启动研学助手.cmd`，前提是 `node` 在系统 PATH 中。
3. 双排序入口：<http://127.0.0.1:8787/#ranking>。页面默认载入[三候选 EGFR 2ITW 教学数据](会前准备/三候选EGFR_2ITW教学双排序_已回对接.json)；若浏览器以前导入过数据，点击“恢复当前三条核验资料”加载新版。

`127.0.0.1` 只在运行服务的电脑上可访问；GitHub 仓库本身不会自动托管可公开访问的网页。

## 当前边界

EGFR 野生型 2ITW 结构的共晶药物 ITQ 回对接首位姿势 RMSD 为 0.913 Å，通过预设的 2 Å 检查；三候选已按同一设置对接，三次随机种子的分数次序相同。页面初始门槛设为 45，以展示三候选的常规／冷门双排序；程序基础默认门槛 50 时仅槲皮素入队。这是参数敏感性教学演示，**不是经科学校准的正式排名或药效结论**。三候选仅通过 SwissADME 的两项基础性质预筛，且都有 PAINS/CYP 预测警示；这不是安全性结论。详见[对接复现记录](会前准备/对接复现/README.md)。元器智能体目前实现 EGFR 教学资料问答，不等于已实现自动筛药或实验验证。

本快照有意排除本地 API 密钥、Python 第三方依赖、Vina 可执行文件和内部页面截图。重跑对接试算时需另行安装 `对接复现/README.md` 所列工具；原始结构、准备脚本、对接日志和结果文件已保留。

## 公网演示与自行部署

项目根目录提供 `Dockerfile`。公网运行时，容器内监听 `0.0.0.0:8787`，须用 HTTPS 反向代理提供访问，并设置运行环境变量：

| 变量 | 用途 |
|---|---|
| `PUBLIC_ORIGIN` | 完整的公网 HTTPS 来源，例如 `https://demo.example.com`；必须与访问域名一致 |
| `DEMO_PASSWORD` | 至少 12 位的独立演示密码；不使用元器密钥充当此密码 |
| `DEMO_USER` | 演示用户名，默认 `demo` |
| `YUANQI_APP_ID` | 元器应用 ID |
| `YUANQI_APP_KEY` | 元器 API 密钥，只填服务器运行环境，不提交 Git |

Docker 公网模式下，浏览器会先要求输入演示用户名和密码；服务限制访问域名、跨站请求、并发聊天和提问频率。没有 HTTPS 地址或演示密码时，服务会拒绝以公网模式启动。`GET /api/health` 可用于同域名健康检查。

现有演示站使用腾讯云中国香港轻量服务器、Nginx Basic 登录和 Let's Encrypt IP 地址证书；Node 仅监听服务器本机。可公开的配置与[实际部署状态](公网部署/当前服务器进度.md)在 `公网部署/`，私有 `.env`、Nginx 密码文件和证书私钥不在仓库。IP 地址证书需要频繁续期，项目已配置每日续期检查。

仓库另提供 Docker + Caddy 部署方式：将 `deploy.env.example` 复制为不会提交 Git 的 `deploy.env`，填写 `DEMO_DOMAIN`、匹配的 `PUBLIC_ORIGIN`、独立演示密码及元器密钥，再执行 `docker compose --env-file deploy.env up --build -d`。Caddy 接管公网 80/443 和 HTTPS；Node 容器不直接暴露公网端口。请使用自己控制的域名，不要在明文 HTTP 页面输入演示密码。
