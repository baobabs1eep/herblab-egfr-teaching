# 中药单体筛选研学助手（EGFR 教学案例）

本仓库是 2026-09-27 的项目演示快照，包含前端页面、本地 Node 服务、双排序程序、教学案例资料与可复核的对接试算记录。腾讯元器智能体的[在线体验入口](https://yuanqi.tencent.com/webim/#/chat/vcaDuu?appid=2103722870126603328&experience=true)单独运行；网页内聊天需要自行配置元器 API 密钥。

## 本地运行

1. 安装 Node.js。在 `本地服务` 目录将 `.env.example` 复制为 `.env`，把 `YUANQI_APP_KEY` 填为自己账号的元器密钥；不要提交 `.env`。
2. 在项目根目录执行 `node 本地服务/server.cjs`，浏览器访问 <http://127.0.0.1:8787/>。Windows 可双击 `启动研学助手.cmd`，前提是 `node` 在系统 PATH 中。
3. 双排序入口：<http://127.0.0.1:8787/#ranking>。可导入 `会前准备/三候选对接试算_验证未通过_不作正式排名.json` 查看真实试算分数、已查文献热度和待补状态。

`127.0.0.1` 只在运行服务的电脑上可访问；GitHub 仓库本身不会自动托管可公开访问的网页。
